# 공룡 1

[운영 서비스](https://ai-sherpa-lessons.yoon2566.workers.dev/)

2026-11-03 운영 Worker에서 추출한 실행 코드와 정적 파일의 공개 스냅샷입니다. 원본 개발 이력은 포함하지 않습니다. 운영 키, 비밀번호, 학생 작품 및 데이터베이스 내용은 포함하지 않습니다.

## 실행·배포

Node.js 22 이상에서 `npm install` 후 `npm run dev`로 실행합니다. `npm run check`는 업로드 없이 번들 구성을 검사합니다.

배포 전 wrangler.json의 이름을 본인 서비스 이름으로 변경하고, D1 항목이 있으면 새 데이터베이스를 생성하여 ID를 입력하세요. schema 폴더가 있으면 필요한 스키마를 새 DB에 적용하세요. 기존 운영 DB는 연결하지 않습니다.

필요한 비밀값(값은 제공하지 않음): `SHERPA_OPENROUTER_KEY`. 각각 `npx wrangler secret put 이름`으로 설정하세요.

설정 후 `npm run deploy`로 본인 계정에 배포할 수 있습니다. 이 스냅샷을 새 계정에 실제 배포하거나 전체 기능 시험을 하지는 않았습니다.

기존 코드와 자료의 저작권·라이선스는 각 원저작자에게 있습니다. 공개 저장소라는 이유만으로 모든 자료의 자유 재배포를 허가하는 것은 아닙니다.
